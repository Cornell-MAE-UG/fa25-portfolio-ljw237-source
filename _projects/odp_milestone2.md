### Initial Sketch

![Initial Sketch]({{ "/assets/images/odp_m2_sketch.png" | relative_url }})

The prototype consists of two wooden columns mounted on a plywood base. Tubing is wrapped helically around each column to mimic grapevines, filled with Tree of Heaven sap pumped from a reservoir inside the base. A 60Hz speaker is mounted between the columns to attract spotted lanternflies.

### Design Estimates

**Power System:** The two powered components are a peristaltic pump for fluid delivery and a 60Hz speaker. Using 4mm diameter tubing with ~30 holes at 1 drop/min each gives a required flow rate of ~1.5mL/min. A 12V micro peristaltic pump drawing 2–5W handles this. A 1.75" subwoofer delivers 60Hz at 72 decibels using 10W. A 12V 5000mAh LiPo battery powers the system.

### Assembly Process

![Assembly Sketch]({{ "/assets/images/odp_m2_assembly.png" | relative_url }})

**Step 1 — Base Construction**
Assemble plywood base box, install hinges and latch, install internal mounts for electrical components, secure two wooden columns to base.

**Step 2 — Fluid System Installation**
Mount fluid reservoirs and peristaltic pumps inside base. Connect reservoir → pump → tubing → vine loops. Add check valve and pressure test with water.

**Step 3 — Vine Tubing Wrapping**
Wrap tubing helically around poles, secure using printed clips, drill evenly spaced 1mm holes, test drip rates, install sprinkler caps.

**Step 4 — Electrical Installation**
Mount speaker centrally between poles. Wire battery → PDP → cycle timer → pump, and PDP → speaker.
